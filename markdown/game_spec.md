# GravityNotes ゲーム仕様定義書

本作「GravityNotes」は、4つの面（Floor・LeftWall・Ceiling・RightWall）と3つのレーンから構成される3Dトンネル空間を舞台にした、3Dリズムアクションゲームです。

---

## 1. シーン構成 (SCENE)

ゲームは以下の5つのシーンで構成されています。

*   **`SCENE_TITLE` (タイトル)**
    *   ゲーム起動時の初期画面。決定キーでステージセレクトへ遷移します。
*   **`SCENE_STAGESELECT` (ステージセレクト)**
    *   遊ぶステージ（譜面）を選択する画面。BGMの試聴、サムネイルの読み込み、難易度情報の取得が行われます。
*   **`SCENE_GAME` (メインゲーム)**
    *   3秒間の猶予カウントダウンの後、BGM再生と同時に奥からノーツが迫る本編。プレイヤーはノーツの種類に応じた操作を行います。
*   **`SCENE_RESULT` (リザルト)**
    *   ゲームクリア/ゲームオーバー時のスコア、コンボ、評価等の集計結果を表示する画面。
*   **`SCENE_DEBUG` (デバッグシーン)**
    *   カメラやライティング、モデルの動作検証などを独立して確認できるシーン。

---

## 2. プレイヤー操作と空間仕様

プレイヤーは3Dのチューブ（トンネル）形状の空間内に存在します。
*   **面 (Face)**:
    *   `0: FLOOR` (床)
    *   `1: LEFT_WALL` (左壁)
    *   `2: CEILING` (天井)
    *   `3: RIGHT_WALL` (右壁)
*   **レーン (Lane)**:
    *   各面上に3本のレーンが存在します。
    *   内部データ値: `-1` (左), `0` (中央), `1` (右) （JSON譜面上は `0`, `1`, `2`）

プレイヤーは面を切り替え、レーンを移動しながら迫るノーツに対処します。

---

## 3. ノーツ仕様と判定

譜面から読み込まれるノーツは以下の種類があり、それぞれ異なる判定と操作が必要です。

| ノーツ種類 | 判定ロジック | 成功時の操作 / 挙動 | 失敗条件 |
| :--- | :--- | :--- | :--- |
| **Enemy (敵/Tap)** | タイミング判定 | 判定タイミング（`HIT_ZONE_Z`）に合わせてタイミングよくボタンを押す。 | 押さずに通り抜けるとミス（Miss） |
| **Orb (オーブ)** | 自動接触判定 | プレイヤーがそのノーツと同じレーン・面に重なるだけで自動回収（`HIT_ZONE_Z` より少し手前から回収開始）。 | 回収できずに通過するとミス |
| **Barrier (障害物)** | 回避判定 | ノーツが通過する瞬間に、プレイヤーが**「そのレーン・面と異なる位置」**にいれば自動的に回避成功（無音コンボ加算）。 | ノーツ通過時に同じレーン・面にいると衝突してミス |
| **Hold (ホールド)** | 長押し判定 | 開始タイミングから終了タイミングまでボタンを押し続ける。 | 途中で離す、または開始時に押し損ねるとミス |
| **RopeHold (レインボー)** | 特殊ホールド | 特殊なホールドノーツ。プレイヤーの足元に引き寄せてホールドすることで進行度が溜まり、完了時に判定されます。 | 途中でホールドが外れるとミス |

---

## 4. 開発・デバッグ用オプション仕様 (`options.yml`)

ルートディレクトリの [options.yml](file:///c:/Users/realryo1/Desktop/GravityNotes/options.yml) を編集することで、テストプレイを快適に行うための設定が可能です。

*   **直接再生 (`directplay`)**:
    *   譜面JSONのパス（例: `"asset/score/tutorial.json"`) を指定すると、起動時にタイトルやステージセレクトをスキップし、直接その譜面でゲームプレイが開始されます。
*   **開始小節 (`startmeasure`)**:
    *   `1` 基準（1が曲の先頭）で小節番号を指定します。指定した小節のタイミング（例: `10`小節目）からBGM再生およびノーツのスポーンがシークされた状態で、3秒のカウントダウン後にスタートします。
